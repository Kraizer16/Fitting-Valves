# Fitting Valves

Sitio web corporativo de Fitting Valves, empresa dedicada a la comercialización de válvulas, tuberías, conexiones y soluciones industriales.

## Tecnologías utilizadas

- React
- JavaScript
- Tailwind CSS
- Vite
- React Router
- EmailJS
- Lucide React

## Características

- Diseño adaptable a dispositivos móviles y escritorio.
- Catálogo de productos industriales.
- Información corporativa de la empresa.
- Formulario de contacto integrado con EmailJS.
- Acceso directo a WhatsApp.
- Navegación entre secciones.

## Ejecución local

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

Generar versión de producción:

```bash
npm run build
```
